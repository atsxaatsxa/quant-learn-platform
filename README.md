# 量化投资学习平台 · MVP

> 面向**零金融 / 零编程基础网民**的量化投资学习与实践平台。
> 把专业量化平台（聚宽 / 米筐风格）的能力，与 B 站《365 天量化金融》的教学设计结合：
> **让零基础新手第一次就能跑通「数据 → 回测 → 报告」完整链路 + 内置学习路径。**

---

## 一、它是什么（30 秒看懂）

| 你想做的事 | 平台怎么做 |
|---|---|
| 不懂代码也想跑个回测 | 「学习路线图」里点一步按钮，自动跑通，报告立刻出来 |
| 想知道指标啥意思 | 每个金融术语首次出现都附一句白话解释（术语白话表） |
| 想改改参数试试 | 策略配置页填表单（免代码），如双均线快/慢线周期 |
| 想写自己的策略 | 勾选「代码编辑入口」，用受限 Python 写 `decide()`（进阶） |
| 想看结果靠不靠谱 | 报告里单独给出「守恒校验」「异常检测」「确定性指纹」 |

**红线（必须知道）**：本平台仅用于**学习研究**，所有结果都是**历史回测模拟**，
**不接入实盘、不承诺收益、不构成投资建议**。

## 二、环境要求

| 项 | 版本 / 说明 |
|---|---|
| Python | 3.13.x（已验证 3.13.14） |
| 操作系统 | Windows / macOS / Linux（单机可运行） |
| 第三方依赖 | 仅 `akshare`（拉数据）+ `pandas` + `numpy` |
| Web 服务 | **零额外依赖**，用标准库 `http.server`（无需 Flask/FastAPI） |

> 数据默认使用**免费公开数据源**（新浪财经 / 东方财富），首次运行联网抓取并缓存到
> `data/cache/*.csv`，之后直接读本地，可离线复现。

## 三、快速开始（5 步）

```bash
# 1) 进入项目根目录
cd quant-learn-platform

# 2) 安装依赖（只需一次）
pip install -r requirements.txt

# 3) 初始化数据（拉取并缓存默认标的池：茅台/平安/招行 + 沪深300 + 沪深300ETF）
python tools/init_data.py
#    若需强制重新联网抓取： python tools/init_data.py --refresh

# 4) 启动 Web 服务（默认端口 8000）
python server.py

# 5) 浏览器打开
#    http://127.0.0.1:8000
```

打开后：
- 进入「① 学习路线图」页，从第 1 步一路点到底；
- 或进入「② 策略配置」页，选策略、填参数、点「运行回测」；
- 报告在「③ 回测报告」页查看（净值曲线 / 指标卡 / 月度 / 成交台账 / 异常）。

## 四、复现样例报告（交付物 ②/③）

同一区间（默认 `2021-01-01 ~ 2023-12-31`）跑通 3 个模板策略，输出到 `outputs/`：

```bash
python tools/generate_sample_reports.py
```

生成内容：

| 文件 | 说明 |
|---|---|
| `outputs/<key>_report.json` | 完整回测报告（指标 / 日频 / 月度 / 成交 / 异常 / 守恒） |
| `outputs/<key>_daily_nav.csv` | 日频净值明细 |
| `outputs/<key>_monthly.csv` | 月度汇总 |
| `outputs/<key>_nav_curve.svg` | 净值曲线（策略 vs 基准，离线 SVG） |
| `outputs/sample_backtest_report.md` | 三策略同区间对比汇总说明 |

样例结论（真实 2021–2023 熊市，已含佣金/印花税/滑点，无前瞻）：

| 策略 | 年化收益 | 夏普 | 最大回撤 | 成交笔数 |
|---|---|---|---|---|
| 买入持有（茅台/平安/招行） | -10.30% | -0.495 | 47.99% | 3 |
| SMA 双均线（沪深300, 5/20） | -10.19% | -1.262 | 30.12% | 50 |
| 月度再平衡（默认池） | -10.04% | -0.490 | 47.48% | 111 |

> 三个报告均通过守恒校验（逐日净值对账偏差 ≤ 3.3e-16），且对数据源返回顺序**打乱 20 次结果逐位一致**。

## 五、项目结构

```
quant-learn-platform/
├── config.yaml                 # 单一事实来源：标的池/区间/成本/风控阈值
├── requirements.txt            # 锁定依赖
├── server.py                   # 标准库 http.server Web 服务（端口 8000）
├── backend/
│   ├── data/datasource.py      # 免费数据源接入 + 本地缓存 + 复权说明
│   ├── engine/
│   │   ├── backtest.py         # 日频回测引擎（无前瞻 / 成本 / 涨跌停 / 守恒）
│   │   ├── costs.py            # 佣金/印花税/滑点 + 涨跌停判定
│   │   ├── metrics.py          # 绩效指标 + 公式字符串
│   │   ├── reconciliation.py   # 守恒校验（独立用台账重算净值）
│   │   ├── validation.py       # 输入自证（维度1，违规则阻止运行）
│   │   └── exceptions.py       # ValidationError（一票否决拦截）
│   ├── strategies/
│   │   ├── base.py             # 策略基类
│   │   ├── templates.py        # 3 个参数化模板 + 课程文案
│   │   └── registry.py         # 策略注册 + 代码模式（受限 exec）
│   ├── teaching/roadmap.py     # 12 步可执行教学路径 + 术语白话表
│   ├── report.py               # 报告组装（结果层）
│   ├── runner.py               # 编排：校验→数据→引擎→守恒→报告
│   └── static/                 # 前端（原生 HTML/CSS/JS，离线 SVG 图表）
├── tools/
│   ├── init_data.py            # 数据初始化 / 刷新缓存
│   └── generate_sample_reports.py  # 生成样例报告
├── data/cache/                 # 行情缓存 CSV（可人工复核）
├── outputs/                    # 样例报告输出
└── docs/
    ├── operation_guide.md      # 《运行与验收说明》
    ├── metric_formulas.md      # 指标公式与假设
    └── self_check_report.md    # 《自查评估报告》（10 分 / 7 维度 + 一票否决）
```

## 七、已知限制（已实现透明标注，非隐藏）

1. 默认交易池为**示意性选取**（茅台/平安/招行），**非无幸存者偏差的历史全集**；专业研究需历史成分股快照。
2. 基准（沪深300）使用**价格指数**，未含分红再投资（保守口径，收益略偏低）。
3. ETF 前复权依赖东方财富，限流时回退新浪未复权并标注「待人工复核」，不伪装成前复权。
4. 焦点为「新手全链路跑通」；因子研究、模拟交易、蒙特卡洛模拟等已在 UI 中标为「规划中」。

详情见 `docs/operation_guide.md` 与 `docs/self_check_report.md`。
