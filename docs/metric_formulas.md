# 指标公式与回测假设

> 配套交付物 ③ 的口径基准，也被回测报告（`backend/report.py` → `metrics.formulas`）与前端「指标公式」折叠区引用。
> 所有口径与《365 天量化金融》课程定义保持一致，并采用**保守口径**（收益宁可偏低、不可虚高）。

---

## 1. 回测执行规则（影响所有指标的根基）

| 规则 | 说明 | 代码位置 |
|---|---|---|
| 无前瞻偏差 | 信号于**第 t 日收盘**基于截至 t 日可得数据生成；成交于**第 t+1 日开盘**执行 | `backend/engine/backtest.py:run()`、`_execute_targets()` |
| 复权价 | 全程使用**前复权(qfq)** 价计算收益与净值 | `config.yaml: data.adjust = qfq` |
| 佣金 | 成交额 × 万3，单笔最低 5 元，**买卖双向** | `backend/engine/costs.py:compute_trade_cost()` |
| 印花税 | 成交额 × 万5，**仅卖出** | 同上 |
| 滑点 | 开盘价 ± 千1（买价更高、卖价更低，保守） | `backend/engine/costs.py:apply_slippage()` |
| 涨跌停 | **股票**涨停不可买、跌停不可卖（前复权空间内用涨跌幅比值判定） | `backend/engine/costs.py:detect_limit_status()`、`is_tradable()` |
| 停牌/无行情 | 不可成交，逐日标注 `no_price`/`valuation_*`，**不静默跳过、不填充** | `backend/engine/backtest.py:_record_day()` |

## 2. 核心指标公式

设日频净值序列为 `NV_0, NV_1, ..., NV_T`（初始 `NV_0 = 1.0`），交易日数 `n`，
年化因子 `tdy = 252`，无风险利率 `rf = 0.02`。

| 指标 | 公式 | 备注 |
|---|---|---|
| 净值 NV | `NV_t = 组合市值_t / 初始资金`；`NV_0 = 1.0` | 现金 + Σ(持仓×收盘价) / 初始资金 |
| 累计收益率 | `NV_T / NV_0 − 1` | — |
| 年化收益率 | `(NV_T / NV_0)^(tdy / n) − 1` | n 为有效交易日数 |
| 日收益率 | `r_t = NV_t / NV_{t-1} − 1` | 仅相邻两日均可估值时计算；缺失日**不跨日计算** |
| 年化波动率 | `std(日收益率) × √252` | 总体标准差 `ddof=0`（与 `numpy.std` 默认一致） |
| 夏普比率 | `(年化收益率 − rf) / 年化波动率` | `rf = 0.02` 取正，拉低夏普，**保守**；波动为 0 时返回 None |
| 最大回撤 | `max_t { (历史峰值NV − NV_t) / 历史峰值NV }` | 衡量「最惨能亏多惨」 |
| 卡玛比率 | `年化收益率 / 最大回撤` | 回撤为 0 时返回 None |
| 基准对比 | 同上口径对 `bench_nav` 计算，得基准年化/累计/超额 | 基准用沪深300 价格指数（未含分红，保守） |

> 公式字符串由 `backend/engine/metrics.py:_formula_strings()` 显式定义，并在报告 `metrics.formulas` 与前端展示，**不只存在于代码注释**。

## 3. 月度汇总口径

| 字段 | 口径 |
|---|---|
| 月收益 `month_return` | 该月内 `月末净值 / 月初净值 − 1` |
| 月末净值 `month_end_nav` | 该月最后一个可估值日的净值 |
| 月内最大回撤 `month_max_drawdown` | 该月内峰值到谷值的最大回撤 |

| 交易日 `trading_days` | 该月内可估值日数量 |

## 4. 守恒校验（维度 2）口径

`backend/engine/reconciliation.py:reconcile()` 独立重算，不依赖引擎累加值：

- **标的总数守恒**：`Σ买入份额 − Σ卖出份额 = 期末持仓`（每个标的 `ok = True`）。
- **净值守恒**：仅用 `初始资金 + 成交台账（含每笔佣金/印花税）` 重算每日 `现金 + Σ(持仓×收盘价)`，与引擎记录净值逐日比对，`max_abs_diff` ≤ 容忍度 `1e-6`。
- **期末现金**：重算现金 = 报告末日 `cash`。

实测：`buy_hold / sma_dual / monthly_rebalance` 三报告的 `all_match = True`，`max_abs_diff ≈ 3.3e-16`（浮点级一致）。

## 5. 异常检测（维度 5）分类

| 类型 | 触发 | 报告分组 |
|---|---|---|
| 数据/估值异常 | 停牌/无行情/估值用前收估算 | `data_issue`（待人工复核） |
| 市场监管约束 | 涨停不可买/跌停不可卖 | `market_constraint` |
| 异常收益 | 单日组合收益绝对值 > `abnormal_return_threshold`(20%) | `abnormal_return` |

代码：`backend/report.py:_group_anomalies()`；分组结果在报告 `anomalies` 与前端「异常检测」区展示。

## 6. 保守性小结（为什么结果偏低而非偏高）

1. 无风险利率取正（2%）→ 夏普被压低。
2. 成本（佣金/印花税/滑点）**逐笔实扣**，非忽略。
3. 基准用价格指数（不含分红再投资）→ 基准本身偏保守，策略超额更难看高。
4. 无前瞻：信号次日才成交，不偷看未来。
5. 缺失数据不打折扣（不填充、不估算收益），宁可标「待复核」。

> 以上口径共同保证：本报告呈现的是**被系统性压低、可被信任**的历史模拟结果，而非「看起来很美」的回测。
